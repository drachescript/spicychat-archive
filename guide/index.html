Archive for Dummies

Your favorite SpicyChat bot disappeared? Here is how to find it, see what was saved, and decide what you can recover.

This page is the quick beginner-friendly guide. For detailed explanations, advanced tools and more technical information, read the in-depth SpicyChat Archive guide.

First: can the original bot be restored?

No, not by this website. SpicyChat Archive is independent from SpicyChat. It cannot undelete a bot, restore its original ID, transfer an old chat to a new bot, contact creators for you, or retrieve hidden definitions. If a bot is truly deleted, only the creator or platform can determine whether an original can return. Recovery Lab helps you build a separate copy from information you are allowed to use. It cannot override moderation or privacy restrictions.

Sometimes a bot is temporarily unavailable, unlisted or private rather than deleted. Do not assume that one failed search proves deletion.

1. Find the bot ID

The ID is a unique string of letters, numbers and dashes. It is not the character's name, picture, creator name or the conversation ID.

On a PC or in a browser

  1. Open the bot's profile or an existing chat with it.
  2. Copy the address from the browser address bar. You can also use the bot's Share option if it still works.
  3. Keep the first UUID immediately after /chatbot/ or /chat/. A second UUID in a chat link belongs to the conversation, not the bot.

Example profile link (illustrative):

https://spicychat.ai/chatbot/11111111-2222-4333-8444-555555555555

Example chat link:

https://spicychat.ai/chat/11111111-2222-4333-8444-555555555555/aaaaaaaa-bbbb-4ccc-8ddd-eeeeeeeeeeee

Copy the highlighted part, or paste the whole link into Public bots, Deleted bots or Archive Search. The direct archive-record link works independently of the current listing filters. Links with a language prefix such as /ru/chatbot/ work the same way. Even if the old chat header is blank, its browser address may still contain the ID.

On a phone

  1. If the native app has a Share or Copy link option, try that first.
  2. If it does not work, sign into SpicyChat in your mobile browser and try opening the existing chat or profile there.
  3. Tap the browser address bar and copy the URL. If the chat no longer opens, check previously saved links or browser history.

Do not send your password, cookies or session tokens to anyone. When asking for help, share only the bot ID or profile link, not the full private conversation URL.

2. If you cannot find the ID

Start with the information you remember. A screenshot showing the character's name and the creator's @username can help narrow the search.

  1. Open Deleted bots and search the name or ID. Also try Archive Search for historical records.
  2. Try Public bots if the bot may still be available. Search the creator's name if you know it.
  3. Try distinctive words from the title, alternative spellings, or a shorter portion of the name. Clear include/exclude tag filters or locally hidden bots if you cannot see a result.
  4. Compare creator, title and picture to make sure you found the right bot. Several bots may have the same name.

If you only remember an image, use any visible text or creator details from it. There is no guaranteed reverse-image search for every archived bot. If the archive never saw the bot, it may not have any record.

3. Open the archive record

  1. Click the matching bot to open its Archive page. If you know the UUID, you can also open Recovery Lab directly and paste the ID or profile link.
  2. Look at the saved name, title, greeting, personality, scenario, example dialogue, tags and image, where available. Check historical versions if the creator changed the bot.
  3. Use the recovery link on the bot page, or open Recovery Lab and click Load archive evidence.

4. Save your existing conversations

If you can still read the chat, save a personal backup before closing or deleting it. You do not need to upload your chat to Archive.

  1. On desktop, install the optional DragonScript SpicyChat QoL extension from its official listing if you want an export tool. S.AI Toolkit exports are also supported by Recovery Lab.
  2. Open the existing chat and use the extension's conversation export feature. If the chat is still accessible, save as much of the conversation as possible. Check that the export actually contains the messages.
  3. Without an extension, copy accessible conversation text into a local text file or directly into Recovery Lab. You can use a supported JSON/HTML transcript, Markdown or plain text. On mobile, use the browser or copy accessible text if no export feature is available.

Export tools cannot retrieve chats that SpicyChat no longer makes available to your account. Keep your export private.

5. Rebuild a character in Recovery Lab

You are making a new copy, not restoring the original. Follow the sections on the page in order.

  1. Choose a bot. Paste its URL or UUID and click Load archive evidence. Select an older version under Base recovery on if appropriate.
  2. Check the evidence. The readiness panel shows which of the eight supported fields have archived values. A present field is not necessarily a complete field.
  3. Add conversation evidence. Drop the export into the upload box, or paste text into the text box and click Use pasted conversation. Review the detected messages. Choose whether user, OOC or regenerated messages should contribute.
  4. Fill missing fields. Type your own content, use Quick Draft (offline), or copy the prompt for an AI tool you choose. If offered, Browser AI or External AI can propose text. Review suggestions and apply only the parts supported by your evidence. Expand proposes additions to existing fields.
  5. Choose an approach. Reconstruct Original uses saved fields as evidence; Make It Mine is for an intentionally adapted version. Neither approach restores hidden data. Keep your own edits and inferred details distinct from actual archived text.
  6. Edit & export. Check the name, title, greeting, personality, scenario, dialogue, tags and picture. Fix mistakes or leave unknown details blank. Download a recovery package as a backup and use Copy fields for manual creation.

Conversation parsing happens locally in your browser. External AI is optional: only use it if you trust the destination and consent to sharing the selected evidence. A recovery package excludes raw conversation message text, but reconstructed fields can contain information from your conversation, so review before sharing.

6. Create your own new bot

  1. Keep a local recovery package so you do not lose your work.
  2. On SpicyChat, use Create → Chatbot. Copy each reviewed field into its matching editor field. If a supported import tool is available, follow its import instructions instead; Archive JSON and PNG exports are not guaranteed to be native SpicyChat imports.
  3. Use an image you have permission to use. Recovery Lab may offer Download archived picture or Use archived picture URL when an image is available; old image URLs may stop working.
  4. Review the new bot against the platform's current rules and respect the creator's rights. Keep personal copies private where appropriate; never recreate content to evade platform moderation.
  5. Save and start a new conversation. The new bot has a different ID. Old conversation history, memories, ratings and private rule states are not automatically carried over.

Other export formats: character-card JSON and PNG are useful for compatible tools; field JSON is useful for reviewing or transferring text. None is a one-click undelete.

7. What about Lorebooks and Rulebooks?

Check Deleted Lorebooks, Deleted Rulebooks, or the public directories in More. A listing, cover or attached-bot count does not mean the full book was saved. Only legitimately shared content can be recovered; hidden instructions, private entries, and private per-chat meter values cannot be recreated from a listing. Observed attachment links may help you locate related records.

Still stuck?

Nothing appears when I search.

Try both public and historical search, clear filters, and check the ID and spelling. If there is no saved record, use Recovery Lab with the ID and your own conversation evidence if available.

I cannot share the bot from the app.

Try the browser version of SpicyChat or check browser history. If all you have is a screenshot, use the visible bot name and creator in Archive Search. Do not assume the profile must have a saved copy.

The archive only has a greeting or picture.

That is all that was captured, not an error. Rebuild missing fields from conversation evidence or your own writing, and label them accurately.

My conversation export does not load.

Check that the file contains actual messages and is a supported format. Try copying a portion of the conversation as plain text. Do not post your private chat export publicly.

Will my old chat or the original bot come back?

No. Archive does not control the original bot or account history. Recovery Lab is a separate character-reconstruction tool.

How do I ask for help?

Share the bot's public ID, name, creator and a short description of the problem in the QoL Discord or on GitHub. Never post your password, cookies, API keys or private chat contents.
