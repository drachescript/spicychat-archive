# SpicyChat Archive

A public archive of SpicyChat bots and Lorebooks. I save what was publicly available so there is still something to look at if a bot is changed or removed.

**Website:** https://spicychatarchive.drache.uk/

You can browse saved bots, check old versions and changes, see bots confirmed unavailable, and use Recovery Lab to rebuild missing character details from whatever evidence is left. There's also Lorebook history, Archive Search, name and tag stats, and tools for comparing records.

Some important limits:

- **Seen** means the Archive recorded a bot ID at some point. It does not mean a complete bot file was saved.
- **Saved** means there is a bot record in the Archive. Some fields may still be missing.
- **Public** is what SpicyChat currently reports. An older sighting doesn't prove a bot is still available.
- **Confirmed gone** requires repeated direct checks, not simply disappearing from search.
- The counts do not always match because they describe different things. A difference in totals is not a list of missing bots.

The Archive also keeps older tag names when SpicyChat removes them from the creator picker. That way you can still filter old records. The retired `Step-Family` tag remains in Archive filters even though it is no longer in the current 90-tag picker.

The project is independent and is not affiliated with SpicyChat.
